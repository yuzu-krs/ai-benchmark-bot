# Model List

<Note>
  Following the Kimi K3 launch, `kimi-k2.5` and the `moonshot-v1` series will be sunset later.
</Note>

## Multi-modal Model

| Model Name                 | Description                                                                                                      |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| `kimi-k3`                  | Kimi's flagship model with native visual understanding, coding, knowledge work, and deep reasoning.              |
| `kimi-k2.7-code`           | Kimi's dedicated coding model for long-context software engineering and agent workflows.                         |
| `kimi-k2.6`                | Supports visual and text input, thinking and non-thinking modes, dialogue, and Agent tasks.                      |

## Generation Model Moonshot V1

| Model Name                       | Description                                                                 |
| -------------------------------- | --------------------------------------------------------------------------- |
| `moonshot-v1-8k`                 | Suitable for generating short texts, context length 8k.                     |
| `moonshot-v1-8k-vision-preview`  | Vision model that understands image content and outputs text, context 8k.   |
